# PC 금융 현황 첫 화면

2026-11-25 · 로컬 샘플 화면

- 대표 지표는 남은 월 예산이다. 월 예산과 확정 지출, 예산 사용률을 같은 영역에 표시한다. 초과하면 초과액을 표시한다.
- 조회 월의 확정 지출을 카테고리별로 나타낸다. 대기 거래 목록에는 거래일 기준 최신 3건까지 표시한다.
- 예산 확인은 샘플 예산 영역으로 이동한다. 대기 거래 검토는 기존 거래 화면에서 검토 대기를 선택한다.
- PC 왼쪽 메뉴와 `#8634a6`을 적용했다. 투자·외화는 화면 구현 전 준비 상태로 표시하고, 결산·보고서는 기존 연결 원장으로 이동한다.
- 기존 브라우저 샘플은 유지한다. 새 샘플은 확정 지출 373,900원, 월 예산 720,000원, 대기 거래 4건으로 시작한다.

## 검증

- 로컬 브라우저에서 남은 월 예산 346,100원, 최근 대기 거래 3건, 예산 확인·거래 검토 이동, 왼쪽 메뉴 접기와 펼치기를 확인했다.
- TypeScript 검사와 변경 파일의 공백 검사를 통과했다.
