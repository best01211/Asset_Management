# 2026-11-25 Q79 기준 소스 반영

## 목적과 변경 파일

새 저장소에서 Q77~Q79 작업을 이어갈 수 있도록 사용자가 제공한 `finance_mvp_q79.zip`의 파일 11개를 초기 기준으로 가져왔다.

- `supabase/migrations/`에 금융 계정, 대기 거래, 원장 및 승인 RPC 마이그레이션을 추가했다.
- `supabase/tests/`에 승인·사용자 격리·알림 중복 검증용 SQL 스크립트 세 개를 추가했다.
- `src/app/api/`와 `src/lib/supabase/`에 대기 거래 생성·승인 라우트와 서버 인증 예제를 추가했다.
- `docs/`에 API 계약, 개발 지시서, 검증 로드맵을 보존했다. ZIP 내부 README는 `docs/Q79_PACKAGE_README.md`로 옮겼다.
- 루트 `README.md`의 프로젝트 지시 사항을 유지하고, 소스 확보 상태와 기준 문서 링크를 갱신했다.

## 검증 결과

- 가져온 파일 11개의 내용이 ZIP 원본과 일치하는지 비교하고 README 링크를 확인했다.
- 현재 기준 소스에는 Next.js 패키지 설정·Android 프로젝트·로컬 Supabase 설정이 없고, 작업 환경에서 Docker·Supabase CLI·`psql`을 찾지 못했다. SQL 통합 테스트와 Next.js 빌드는 미실행이다.

## 남은 작업

로컬 DB·API에서 기준 동작을 재현한 뒤 C-3·C-5·C-6의 확정 원장 불변성, 승인 원자성, 계정 및 접근 권한 검증을 진행한다.
