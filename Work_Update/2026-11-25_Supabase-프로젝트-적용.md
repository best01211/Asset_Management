# Supabase 프로젝트 적용

2026-11-25 · 서울 리전

- 연결된 조직에 `Asset Management` 프로젝트를 만들고 새 공개 스키마에 저장소의 SQL 마이그레이션 23개를 적용했다.
- 원격 이력에 기록된 마이그레이션 버전 번호를 로컬 파일과 일치시켰다. 양쪽에서 이름과 버전 23건이 모두 같은 것을 확인했다.
- 공개 스키마 테이블 27개에 RLS가 켜져 있다. 익명 사용자는 구매 승인 RPC를 호출할 수 없다. 영수증 버킷은 비공개이며 JPEG·PNG·PDF, 4 MiB로 제한된다.
- 원격 DB에서 가상 구매 승인·집계와 다른 사용자 읽기 차단, Storage 오브젝트 메타데이터의 소유자 읽기와 다른 사용자 읽기·쓰기 차단을 확인했다. 확인용 데이터는 모두 롤백했다.
- Supabase 보안 어드바이저에 오류 등급 항목은 없었다. 인증 사용자에게 실행 권한을 부여한 `SECURITY DEFINER` 함수에 관한 경고가 남아 있다.
- Next.js 배포, 실제 브라우저 인증 세션 및 영수증 파일 업로드·복원 검증은 별도 단계다.
