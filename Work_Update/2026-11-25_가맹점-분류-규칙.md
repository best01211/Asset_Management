# 개인 가맹점 분류 규칙

2026-11-25 · 로컬 구현 및 검증

- 계좌·카테고리 설정에서 가맹점 이름과 기본 카테고리를 연결하고, 저장한 규칙을 수정하거나 삭제할 수 있다.
- 새 구매를 입력할 때 가맹점 이름의 앞뒤 공백과 영문 대소문자를 무시해 일치하는 규칙을 찾는다. 카테고리가 비어 있을 때 추천값을 채우며 사용자가 직접 선택한 값이 우선한다.
- 규칙은 사용자별로 저장한다. 다른 사용자와 익명 요청은 규칙을 조회하거나 변경할 수 없다.

## 검증

- 격리 PostgreSQL에서 이름 정규화, 전체 이름 일치, 수정·삭제, 사용자별 접근 제한을 확인했다.
- 로컬 브라우저와 테스트용 API에서 규칙 저장, 새 구매 자동 분류, 수동 카테고리 선택을 확인했다.
- TypeScript 검사와 Next.js 프로덕션 빌드를 통과했다.
