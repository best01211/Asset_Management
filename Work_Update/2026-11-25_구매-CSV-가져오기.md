# 원화 구매 CSV 가져오기

2026-11-25 · 로컬 API

- 사용자가 보유한 계좌와 카테고리를 지정한 UTF-8 CSV를 한 번에 최대 100건까지 검토 대기로 등록한다.
- 원 단위 큰 정수를 문자열로 처리한다. 쉼표, 큰따옴표, 줄바꿈을 포함한 CSV 필드와 BOM을 지원한다.
- 잘못된 행이 있으면 전체 요청이 롤백된다. 내용과 순서가 같은 파일을 다시 보내면 기존 거래 ID를 반환한다. 같은 파일 안의 동일 행은 별개 후보로 보존한다.
- 가져온 거래는 기존 검토·승인 흐름을 사용한다. 거래 원장과 확정 지출에 반영하려면 사용자가 승인해야 한다.

## 검증

- 격리 PGlite에서 잘못된 계좌가 섞인 요청의 전체 롤백, 원 단위 정밀도, 같은 파일 재시도, 사용자별 접근 제한을 검증했다.
- TypeScript 검사와 Next.js 프로덕션 빌드를 통과했다.
- 로컬 프로덕션 서버와 테스트 API에서 CSV 인용 부호와 BOM, 실패 행 번호, 롤백 및 같은 자료의 중복 방지를 확인했다.
