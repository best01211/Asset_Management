# 로컬 백업과 복원 검증

2026-11-25 · 격리 DB 검증

- `npm run db:verify`는 애플리케이션 마이그레이션과 SQL 테스트를 실행한다.
- 가상 계좌와 구매를 만들고 초기 잔액·확정 분개·월말 결산을 기록한다. `pg_dump`로 생성한 논리 백업을 별도 격리 DB에 복원한 뒤 원본의 분개 수, 잔액, 결산과 비교한다.
- 복원 후 다른 사용자에게 원장과 결산이 보이지 않는 것을 확인했다. 임시 샘플과 백업은 검증 실행 중에만 사용한다.
- 실제 Supabase Auth와 Storage 객체 파일의 백업·복원은 운영 배포 승인 뒤 격리된 Supabase 환경에서 별도로 검증해야 한다.
