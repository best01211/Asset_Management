# 2026-11-25 연결된 계좌 설정 및 구매 입력

## 변경 내용

Q2, Q5~Q6, Q16에 따라 연결된 웹에서 결제 계좌·비용 카테고리를 등록하고 수동 구매를 대기 거래로 입력할 수 있도록 했다.

- `20261125024500_create_connected_expense_categories.sql`에서 비용 계정과 카테고리를 함께 만들고, 동일 이름의 등록 요청에 기존 ID를 반환한다.
- 연결된 거래 검토의 구매 입력은 요청 ID를 사용한다. 재시도는 기존 거래를 반환하며, 이미 수정된 대기 거래의 내용을 원래 입력으로 되돌리지 않는다.
- 설정 목록에서 원화 자산 계좌, 카드 부채 계좌, 비용 카테고리를 등록할 수 있다. 결제 계좌의 초기 잔액은 계좌 잔액 화면에서 따로 기록한다.

## 검증

`014_connected_purchase_setup.sql`에서 중복 등록 방지, 사용자 격리, 수동 입력의 대기 상태, 입력 재시도 후 수정 유지 및 확정 상태 반환을 검증했다. 전체 SQL 테스트 14개와 Next.js 빌드·타입 검사를 통과했다.

로컬 브라우저에서 결제 계좌·카테고리 등록과 수동 구매의 대기 목록 반영을 확인했다. 운영 Supabase 연결, 로그인 구현, 원격 업로드는 진행하지 않았다.
