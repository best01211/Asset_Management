# 영수증 원본과 OCR

2026-11-25 · 로컬 서버 API

- 소유한 거래에 JPEG·PNG·PDF를 첨부하고 비공개 Supabase Storage 버킷에서 내려받는다. 파일 크기는 최대 4 MiB다. 내려받은 원본은 브라우저에서 문서로 자동 실행되지 않도록 첨부 응답으로 제공한다.
- PDF의 텍스트를 추출하고 스캔 PDF 및 이미지에는 한국어·영어 OCR을 실행한다. PDF는 최대 5쪽이다.
- OCR 결과는 응답으로 반환된다. 사용자가 결과를 검토하고 영수증 품목 API에 제출할 때 결제액 검증 및 분할 계산이 이뤄진다.

## 검증

- 격리 SQL에서 원본 경로의 소유권과 다른 사용자 업로드 차단을 확인했다. 실제 OCR 엔진으로 테스트 이미지와 스캔 PDF를 읽고, 별도로 텍스트 PDF 추출을 확인했다.
- 로컬 HTTP와 Storage 테스트용 응답에서 이미지 업로드·재전송·원본 복사 일치와 OCR 응답을 검증했다.
