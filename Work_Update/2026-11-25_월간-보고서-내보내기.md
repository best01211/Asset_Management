# 월간 금융 보고서 내보내기

2026-11-25 · 로컬 서버 API

- 지정 월의 확정 지출, 예산, 잔액 및 실제 카드 명세서를 CSV, XLSX, PDF로 내보낸다.
- 저장 결산 버전을 선택할 수 있다. 카드 명세서는 보고서를 요청한 시점의 수치를 별도 표시한다.
- XLSX의 금액을 문자열로 기록해 큰 원화 정수를 그대로 보존한다. CSV는 수식으로 해석될 수 있는 셀을 보호한다. PDF는 한글 글꼴을 포함한다.
- 예약 발송과 외부 전달은 후속 범위다.

## 검증

- 로컬 HTTP와 격리 DB에서 결산 버전 선택, CSV 금액, XLSX 내용, PDF 한글 텍스트를 검증했다. TypeScript 검사와 프로덕션 빌드를 통과했다.
