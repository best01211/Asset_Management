# 월말 결산 버전

2026-11-25 · 로컬 데이터 모델과 API

- 한국 시간 기준 마감한 달의 확정 원장, 예산, 월말 원화 계좌 잔액을 저장한다. 초기 잔액을 확인할 수 없는 계좌는 잔액을 미확인으로 표시하고 확인 가능한 순자산과 구분한다.
- 정정이나 예산 변경으로 현재 값이 달라지면 결산을 다시 저장할 수 있다. 이전 결산 버전과 저장 당시의 수치를 보존한다.
- 결산 조회는 현재 값과 선택한 저장 버전의 변경 여부를 반환한다. 다른 사용자의 결산을 읽거나 수정할 수 없다.

## 검증

- 격리 PGlite에서 한국 시간 월 경계, 미확정 구매 제외, 초기 잔액 미확인 계좌, 기존 결산 보존 및 정정 후 재결산을 확인했다.
- 로컬 프로덕션 서버와 테스트 API에서 인증 없는 조회 차단, 결산 저장, 이전 버전 조회, 버전 충돌을 확인했다. TypeScript 검사와 프로덕션 빌드를 통과했다.
