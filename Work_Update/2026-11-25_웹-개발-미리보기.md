# 2026-11-25 웹 개발 미리보기

## 목적과 관련 요구사항

로그인 화면을 후속으로 미루고 Q2~Q5, Q15~Q16, Q21~Q22, Q26~Q27의 웹 흐름을 먼저 검토할 수 있도록 Next.js 개발 미리보기를 추가했다. 첨부 점검서에서 빠진 Q18 확인은 후속으로 미뤘다.

## 변경 내용

- `package.json`, 잠금 파일, TypeScript 설정과 Next.js 앱 진입점을 추가했다.
- `src/app/dashboard.tsx`와 `globals.css`에 대시보드, 접이식 메뉴, 거래 검색·상태 필터, 수동 구매 입력·수정·개별 및 선택 승인, 계좌 초기 잔액, 카테고리와 반복 월 예산 설정을 구현했다.
- `src/lib/local-finance.ts`에 샘플 데이터와 원화 입력·계좌 잔액 계산을 정리했다. 승인 전 거래는 잠정 합계에만 표시하며 테스트 변경은 같은 브라우저에 보관한다.
- `.env.example`에 Supabase 프로젝트 URL과 publishable key 이름을 적었다. 기존 두 API에 설정이 없을 때 반환할 503 응답을 추가하고 API 계약을 갱신했다. 두 API는 Supabase가 설정된 경우 사용자 세션을 요구한다.
- 루트 README에 로컬 실행과 실제 데이터 연동에 필요한 작업을 기록했다.

## 검증

- Next.js 프로덕션 빌드와 TypeScript 검사 통과.
- 로컬 홈 HTTP 200 및 Supabase 미설정 시 거래 생성·승인 API의 HTTP 503 응답 확인.
- 브라우저에서 거래 입력·수정·선택 승인, 승인 전 집계 제외, 승인 후 확정 지출과 카드 부채 변화, 새로고침 후 저장 유지, 계좌 초기 잔액 및 카테고리 예산 변경을 확인했다.

## 남은 작업

사용자 인증과 화면·Supabase API 연동, 원장과 RLS 통합 테스트, 초기 분개 및 카드 대금 납부·이체·환불, 실제 잔액 대조, 카드·투자 기능이 남아 있다. 배포와 운영 Supabase 연결은 미실행이다.
