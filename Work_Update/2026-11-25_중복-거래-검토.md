# 2026-11-25 중복 거래 검토

## 목적과 변경 내용

Q66~Q68과 점검서 C-7에 따라 중복 의심 거래를 비교하고 검토 결과를 기록할 수 있도록 했다.

- `supabase/migrations/20261125015803_review_pending_duplicates.sql`에 같은 사용자의 비교 상대 관계와 목록·결정 RPC를 추가했다. 같은 통화·금액이고 전후 72시간인 항목을 비교 후보로 최대 20건 표시한다. 사용자가 비교 상대를 정한 후 중복 의심 표시, 검토 대기 복귀 또는 제외를 선택한다.
- 결정마다 거래 버전과 감사 이력을 갱신한다. 제외된 거래와 비교 상대 관계를 보존하며, 확정 분개는 생성하지 않는다.
- `src/app/api/pending-transactions/[id]/duplicates/route.ts`와 거래 검토 화면에 관련 기능을 추가했다. **제외** 상태 조회를 지원한다.

## 검증 결과와 남은 작업

격리 PostgreSQL에서 비교 후보 연결, 중복 의심 거래 승인 차단, 정상 처리 복귀, 제외 후 원장 미반영과 다른 사용자 접근 차단을 확인했다. Next.js 빌드와 타입 검사를 통과했다. 테스트용 Supabase 응답으로 브라우저에서 비교 대상 선택, 정상 처리 복귀, 중복 제외 및 제외 목록 반영을 확인했다. 운영 프로젝트와 실제 수신기에서의 동작은 후속 검증 범위다.

두 DB 세션이 두 거래를 동시에 서로의 원본으로 지정하는 경우도 시험했다. 중복 관계는 한 방향만 저장됐고 다른 요청은 유효하지 않은 참조로 처리됐다.
