# 카드 실제 청구 정산

2026-11-25 · 로컬 데이터 모델과 API

- 카드사 명세서의 월별 청구액과 만기일, 확인한 실제 혜택, 출처를 저장한다.
- 기존 카드 납부 전표를 해당 카드의 명세서에 배정한다. 명세서와 납부 전표 양쪽에서 금액을 초과해 연결할 수 없다.
- 분할 납부, 하나의 납부액을 여러 명세서에 배정, 배정 해제를 지원한다. 배정 변경은 감사 로그에 기록하고 생활 지출 · 원장 전표는 다시 생성하지 않는다.
- 청구서 입력은 수동이다. 카드사 자료 자동 동기화와 실제 회차별 명세서 대조는 후속 범위다.

## 검증

- 12,000원 카드 납부 전표를 두 명세서에 나눠 연결했다. 초과 배정 차단, 배정 해제, 미납액, 확정 원장과 접근 정책을 SQL로 확인했다.
- 로컬 HTTP와 격리 DB에서 청구 3,000원과 기존 납부 2,000원을 연결했을 때 미납액이 1,000원인 것을 확인했다.
