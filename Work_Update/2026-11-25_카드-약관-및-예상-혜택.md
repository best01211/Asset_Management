# 카드 약관 및 예상 혜택

2026-11-25 · 로컬 구현

- 원화 카드 부채 계좌에 사용자가 확인한 약관 출처와 적용 기간, 카테고리, 정률 혜택, 전월 최소 실적, 월 한도를 버전별로 저장한다.
- 구매 예정일에 유효한 약관을 선택한다. 사용자가 입력한 카드사 인정 실적과 남은 한도를 바탕으로 원 단위 내림한 예상 혜택을 계산한다. 화면에 근거 약관과 적용 여부를 표시한다.
- 복합 혜택, 자동 약관 수집, 여러 카드 비교와 실제 혜택 정산은 후속 범위다. 현재 계산은 구매 원장에 영향을 주지 않는다.

## 검증

- 격리 PGlite에서 약관 버전과 유효기간, 월 한도, 실적·카테고리 조건, 입력 금액의 정밀도, 등록 재시도와 사용자별 접근 제한을 검증했다.
- TypeScript 검사와 Next.js 프로덕션 빌드를 통과했다.
- 로컬 브라우저와 테스트용 API에서 7.5% 약관을 등록하고, 월 5,000원 한도에서 이미 4,500원을 사용한 경우 예상 혜택이 500원으로 제한되는 것을 확인했다.
