# 투자 및 외화 거래 기록

2026-11-25 · 로컬 데이터 모델과 API

- 증권 계좌별 매수·매도·배당·환전과 명세서 출처를 기록한다. 문자열 금액을 PostgreSQL 숫자로 처리한다.
- 매수 수수료와 당시 환율을 포함해 원화 이동평균 원가를 구한다. 매도에 배정한 원가, 실현손익, 순배당과 통화별 순현금 이동을 각각 조회한다.
- 입력한 시세·환율·기준일로 현재 보유분의 평가액과 미실현손익을 계산한다. 시세가 없는 보유분은 미확인으로 표시한다.
- 거래 자료는 수동 입력을 사용한다. 실시간 시세·증권사 연동, FIFO, 증권 입출금과 생활비 원장·전체 순자산 통합은 후속 범위다.

## 검증

- 매도 가능 수량 제한, 재시도, 원가와 실현손익·배당·평가액, 신청 통화별 환전 기록, 사용자별 접근을 SQL로 검증했다.
- 로컬 HTTP와 격리 DB에서 계좌 등록, 외화 매수 입력, 시세를 적용한 원화 평가액 136,500원을 검증했다.
