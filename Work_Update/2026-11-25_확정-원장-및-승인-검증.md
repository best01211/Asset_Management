- 루트 README와 검증 로드맵에 새 마이그레이션, 작업 기록, 로컬 테스트 절차를 반영했다.
- Supabase CLI 임시 파일을 Git에서 제외했다.

## 검증 결과

- 격리 PostgreSQL 17.12에서 두 마이그레이션과 SQL 테스트 4개를 실행했다. 기존 승인 흐름, 사용자 격리, 이벤트 재전송, 원장 변경 제한과 승인 실패 시 전부 롤백되는 동작을 확인했다.
- 별도 DB 세션 두 개로 같은 거래를 동시에 승인했다. 같은 요청 키는 동일 확정 거래 ID를 반환했고, 다른 키에는 승인 충돌이 반환됐다. 두 경우 모두 거래 한 건, 분개 두 줄, 승인 요청과 감사 로그 각각 한 건이 남았다.
- PostgreSQL 테스트에서 Supabase 역할과 `auth.uid()`를 테스트용으로 구성했다. Supabase Auth·PostgREST 및 운영 프로젝트에서는 검증을 진행하지 않았다.
