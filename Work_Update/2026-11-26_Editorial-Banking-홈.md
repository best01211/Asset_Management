# Editorial Banking 홈

2026-11-26 · Q2~Q6, Q15~Q17, Q21~Q24, Q54~Q57

## 변경

- 샘플 홈과 연결형 홈에 공통 65:35 레이아웃을 적용했다. 메인 열은 가용 예산과 순자산, 보조 열은 거래 검토·정기 결제·주요 소비 카테고리를 제공한다.
- `globals.css`의 디자인 토큰과 `dashboard.css`의 반응형 스타일을 사용한다. 홈 서체는 로컬 Pretendard Variable 웹폰트다.
- 예산은 확정 지출과 미결제 정기 결제만 차감한다. 연결된 일정이 없으면 정기 결제 반영 전 잔액과 산정 불가 상태를 표시한다. 이미 확정된 거래에 연결된 일정은 샘플 예산에서 중복 차감하지 않는다.
- 순자산 차트는 원화 계좌 잔액과 비교 가능한 월말 결산으로 표시한다. 키보드·포인터·터치에서 날짜별 금액과 자료 출처를 확인할 수 있다. 검증 가능한 연결 구간이 없으면 빈 상태를 표시한다. 월말 결산에서 거래·평가 변동의 원인을 분리할 수 없는 경우 이를 화면에 명시한다.
- 거래 검토 및 알림 복구 링크를 유지했다. 주요 소비 카테고리는 당월 확정 내역으로 연결한다.

## 검증

- TypeScript, ESLint, Next.js 프로덕션 빌드를 통과했다. Windows 샌드박스에서 junction 생성이 제한돼 빌드는 권한을 허용한 실행으로 확인했다.
- `npm run db:verify`에서 마이그레이션 23개, SQL 테스트 25개, 논리 백업 복원과 사용자 격리를 확인했다.
- Edge에서 데스크톱 1440px와 모바일 390px·320px를 검증했다. 예산·거래 승인·카테고리 필터·정기 결제 전체 보기·차트 기간 변경과 키보드 탐색·데이터 부족 상태를 확인했다.
- 연결형 홈은 로컬 Supabase 응답을 사용해 무인증 안내, 정기 결제 데이터 없음, 중복 및 알림 복구 상태, 원장 링크와 월말 결산 공백을 확인했다.

## 남은 작업

- 이 작업에서는 저장소의 참고 자료와 요청 명세로 레이아웃을 구현했다. 첨부 목업은 확인할 수 없었다.
- 투자 자산의 별도 평가 데이터 연동과 운영 Supabase 인증 세션에서의 실제 데이터 검증은 추후 작업이다.

## 홈 구성 및 AI 챗봇 버튼 후속 변경

- 샘플 홈과 연결형 홈의 순자산 변동 내역을 제거하고, 순자산 추이 바로 아래에 주요 소비 카테고리를 배치했다. 카테고리별 확정 거래 링크와 차트의 기간 선택 및 순자산 계산 근거는 이어서 제공한다.
- 공통 웹 레이아웃 오른쪽 아래에 보라색 원형 AI 챗봇 버튼을 추가했다. 자체 챗봇 로고를 사용하고, ChatGPT를 새 탭에서 연다. 기존 계정과 원장 정보는 링크에 포함하지 않는다.
- TypeScript를 포함한 프로덕션 빌드와 ESLint를 통과했다. Edge에서 1440px·390px·320px 홈 구성, 스크롤 중 버튼 위치, 카테고리 필터와 새 탭 이동을 확인했다.

## 데스크톱 열 배치 조정

- 순자산 차트 높이를 240px에서 320px로 늘렸다. 주요 소비 카테고리는 보조 열의 정기 결제 아래로 옮겼다.
- 왼쪽 탐색 사이드바의 배경이 페이지 끝까지 이어지도록 하고, 높이가 낮은 창에서는 메뉴 영역을 스크롤할 수 있게 했다.
- 프로덕션 빌드와 변경 컴포넌트 ESLint를 통과했다. Edge 1440px·1280px에서 오른쪽 열의 가로 잘림과 페이지 하단의 사이드바 위치를 확인했다.

## 1980px 화면 여백 조정

- 데스크톱 콘텐츠의 최대 너비를 1760px로 넓혔다. 섹션 사이 여백을 줄이고 거래 검토 버튼을 제목 옆에 두었다. 순자산 차트는 오른쪽 열의 높이에 맞춰 늘어난다.
- Edge 1980×1080에서 메인 영역 너비 1692px, 차트 높이 약 375px, 두 열의 하단 정렬을 확인했다. 1440px와 1024px에서도 가로 넘침과 차트 키보드 동작을 확인했다. 프로덕션 빌드를 통과했다.

## 데스크톱 홈 확정

- 1980×1080에서 확인한 배치를 홈 기준으로 확정했다. `EditorialHome`을 샘플과 Supabase 연결형 홈에서 공통으로 사용하며, 각 화면의 데이터 소스는 기존 진입점에서 선택한다.
- README에 확정된 데스크톱 레이아웃과 섹션 배치를 기록했다.
- 프로덕션 미리보기에서 1980×1080 샘플 홈과 로컬 Supabase 응답으로 구동한 연결형 홈을 최종 확인했다.
