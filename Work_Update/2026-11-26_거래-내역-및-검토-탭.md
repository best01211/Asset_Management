# 거래 내역 및 검토 탭

2026-11-26 · Q2~Q6, Q21~Q24, Q42, Q53, Q66, Q68, Q75

- `/transactions`에는 확정 거래와 원화 당월 요약을 표시한다. 순지출은 기존 확정 원장 집계를 사용하고, 이체 원금과 카드 대금 납부를 지출로 집계하지 않는다. 투자 내역은 별도 데이터 영역에 있다.
- `/transactions?tab=review`는 기존 연결형 목록·상세 패널 및 단건·일괄 승인, 수정, 분할, 중복 비교를 재사용한다. `id`가 지정되면 해당 대기 거래를 조회한다. 기존 검토 링크는 새 경로로 리디렉션한다.
- 기간은 한국 시간으로 처리한다. 날짜·계좌·카테고리·유형·금액 필터와 거래명·메모 검색을 제공한다. 금액순 정렬은 환산 없이 통화별로 처리한다.
- 확정 거래 상세에서 관련 환불·정정과 감사 이력, 영수증에 접근한다. 원장에 영향을 주는 정정은 기존 흐름을 사용한다. 별도 테이블의 메모·태그는 버전을 검증하고 저장 이력을 기록한다. 배포 환경에서 저장을 활성화하려면 신규 마이그레이션을 적용해야 한다.
- 일괄 수정과 별도 집중 검토 모드는 미구현이다. AI 금융 비서 버튼은 페이지 내 패널을 열며, 대화 백엔드가 연결되기 전까지 ChatGPT 열기 링크를 제공한다.

## 검증

- TypeScript, ESLint, Next.js 프로덕션 빌드를 통과했다.
- 로컬 DB에서 마이그레이션 24개와 SQL 테스트 26개를 실행했다. 메모·태그 저장, 버전 충돌, 감사 기록, 사용자 격리와 논리 백업 복원을 확인했다.
- Edge 데스크톱에서 내역·검토 탭, 필터, 저장하지 않은 메모 보호, 대기 승인 후 내역 반영을 확인했다. 연결형 API는 로컬 Supabase 응답을 사용했다. 좁은 화면에서 상세 패널과 AI 버튼의 위치도 확인했다.

## 당월 확정 거래 목록

- 기본 조회 기간은 한국 시간 기준 이번 달이며, 목록 상단에 실제 적용 기간을 표시한다. 과거 월 링크와 상세 날짜 필터도 지원한다.
- 확정 거래는 10건씩 표시한다. 다음·이전 버튼 옆에 현재 페이지와 전체 결과 중 표시 범위를 표시한다. 상세가 닫혀 있을 때는 테이블이 본문 너비를 모두 사용한다.
- 프로덕션 빌드를 통과했다. Edge 1980×1080에서 당월 확정 거래 23건의 10·10·3건 분할, 대기 거래 제외, 과거 월 링크와 필터 변경 후 페이지 초기화를 확인했다.
