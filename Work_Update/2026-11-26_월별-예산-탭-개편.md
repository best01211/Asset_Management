# 월별 예산 화면 및 탭 개편

2026-11-26 · `/budgets`

## 화면 구성

- 상단에는 조회 월, 전체 예산 설정, 실제 남은 예산, 월말 예상 지출을 공통으로 표시한다.
- 기본 탭인 **예산 현황**에서 카테고리별 사용률과 상세 예산을 보고 수정한다. 승인 대기 거래, 주의·초과 카테고리, 미결제 정기 결제도 이 탭에서 확인한다.
- **소비 분석**은 확정 누적 지출과 균등 사용 참고선, 월말 예상 근거, 규칙 기반 인사이트를 표시한다. 인사이트에서 전역 AI 금융 비서를 열고 질문 초안을 복사할 수 있다.
- **전월 비교**는 진행 중인 달의 동기간 또는 종료된 달의 전체 기간을 비교한다. 전체 카테고리 비교는 펼쳐서 확인한다.
- 탭 전환은 클라이언트 상태로 처리한다. 선택 카테고리를 유지하고, 미저장 예산 수정이 있으면 전환 전에 확인한다. 방향키와 Home·End로도 탭을 탐색할 수 있다.

## 계산과 데이터 연동

- 실제 남은 예산 = 월 목표 예산 − 확정 순지출 − 미결제 정기 결제 잔액. 승인 대기 거래는 별도 표시하고, 일부 결제는 미결제 잔액만 차감한다.
- 월말 예상 지출 = 확정 순지출 + 미결제 정기 결제 잔액 + 남은 기간의 예상 변동 지출. 직전 완료 월의 변동 지출 기록을 사용하며 데이터가 부족하면 예측 불가 상태를 표시한다.
- 전체 예산과 카테고리 배정을 한 번에 저장할 수 있다. 지난달 복사는 현재 조회 월의 편집 초안에 반영되며, 지난달의 저장값은 보존한다.
- 월별 예산 화면 구현에 기존 테이블을 재사용하고 조회·일괄 저장 RPC를 추가했다. 운영 적용에 [월별 예산 마이그레이션](../supabase/migrations/20261126073014_monthly_budget_workspace.sql)이 필요하다. 후속 탭 개편에는 별도 DB 변경이 없다.

## 검증

- TypeScript, ESLint, Next.js 프로덕션 빌드 및 SQL 테스트 29개를 통과했다.
- 로컬 Edge에서 탭 전환 시 추가 조회 방지, 키보드 탐색, 미저장 입력 보호, 오류 후 재시도, 모바일 화면, 예산 수정·복사, 거래 승인 후 반영과 홈 계산 일치를 확인했다.
- 동일한 테스트 데이터와 1980×1080 뷰포트에서 기본 화면 전체 높이가 2,212px에서 1,095px로 줄었다.
