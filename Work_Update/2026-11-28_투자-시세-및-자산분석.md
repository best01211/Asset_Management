# 투자 시세와 자산 분석 화면 개선

- 자산 분석으로 전환할 때 본문이 콘텐츠 너비에 맞춰 줄어들던 문제를 수정했다. 기존 1440px 화면에서 보유 현황은 1002px, 자산 분석은 847px이었다. 두 탭에 같은 본문 너비와 스크롤바 여백을 적용했다.
- 주식 시세와 원화 환율을 Yahoo Finance에서 조회한다. 투자 화면을 보고 있는 동안 1분마다 갱신하며 수동 새로고침도 지원한다. 제공처의 시세 시각을 보존하고 조회 실패 시 마지막 성공값을 유지한다. 거래소별 지연과 휴장 시간이 적용된다.
- 종목별 보유 현황에서 실제 잔고가 있는 계좌 이름을 표시한다. 데모에는 미래에셋증권과 토스증권 보유 사례를 넣었다.
- 포트폴리오 구성 비중을 원화 평가액 기준 도넛 차트로 표시한다. 범례에서 항목별 비율을 확인할 수 있다.
- 시세 응답 검증, 캐시, 일부 종목 조회 실패와 기존 투자 원장 계산을 테스트했다. 데모 API에서 주식 3종 및 원화 환율 2종의 외부 응답을 확인했다.
- 프로덕션 빌드와 린트를 통과했다. Edge에서 1440px 화면의 두 탭 본문 너비는 모두 1183.4px, 390px 화면에서는 모두 343px이었다. 종목별 증권사, 원형 차트, 수동 갱신 실패 시 평가액 유지도 확인했다.
- 총 투자·외화 평가액 아래에 최근 90개 기록일의 원화 평가액 추이를 표시한다. 한국 시간 기준으로 해당 일자까지의 거래를 반영하며 당시 확인된 가격과 환율이 부족하면 선을 끊는다.
- 시세·환율 입력 버튼을 거래 등록 옆에 배치했다. 주식의 가격·환율 출처와 기준 시각은 종목 상세 분석에서 확인한다.

## 과거 종가·환율로 일별 평가액 계산

- 조회 기준일을 변경해 과거 포트폴리오를 확인할 수 있다. 조회 구간 시작 전에 보유한 종목, 구간 중 매수·매도 종목, 거래 및 환전 통화를 조회한다.
- 한국 시간으로 거래와 완료된 일봉을 정렬하고 180일 범위 내 최근 90개 기록일을 표시한다. 조회 기준일이 오늘이면 마지막 점은 상단 총평가액을 사용한다. 과거 평가에 필요한 관측값이 없거나 7일보다 오래됐으면 산정을 보류한다.
- 매수, 전량 매도, 환전, 미래 시세 배제와 시세 누락을 고정 원장으로 검증했다. 외부 API에서 삼성전자, AAPL, 달러·원 일봉 응답을 확인했다.
